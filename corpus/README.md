# corpus/

## `demo-account.csv` — FICTIONAL

Not a record of anyone. Generated by `scripts/make_demo_account.py --seed 4242`,
committed so the demo runs from a fresh clone with no account and no network.

It exists for two reasons.

**Gnosis needs closed positions.** It refuses below thirty, and a real spot
export does not contain thirty closed positions — spot investors accumulate and
hold. The one real Binance export this project was tested against yielded 26
realised trades over a multi-year span and was correctly declined. Futures books close,
so they can be profiled.

**The futures CSV dialect was written against documentation, not a real file.**
This fixture is emitted in that exact format — UTF-8 BOM, CRLF, newest-first,
`Realized Profit` / `Leverage` / `Margin Mode` columns — so parsing it exercises
the half of the parser that no real file had ever touched.

The persona is a composite of documented retail pathologies: disciplined on the
majors in daylight, gambling on an alt at 3am with 25x. Every leak is *made true
in the data*; none of it is asserted. If the detectors stop finding them, that is
a finding about the detectors, which is the point of keeping it.

Regenerate with:

```bash
python3 scripts/make_demo_account.py --out corpus/demo-account.csv
```
